## [1.0.0] — 2026-08-27

Initial release — Node.js CLI for converting Markdown to PDF + Word with Mermaid diagrams, Thai & English support, cross-platform (Linux, macOS, Windows).

### Core
- Markdown → PDF + DOCX conversion via pandoc + XeLaTeX
- Six-stage labeled build pipeline (`[1/6]` … `[6/6]`) with accurate exit-code handling
- Unique per-build output folders (`result/diagrams/{filename}-{rand6}/`) to prevent overwrites
- `src/` modules: `index.js` (orchestrator), `yaml.js`, `paths.js`, `deps.js`, `mermaid.js`, `pandoc.js`

### CLI
- Entry point via `commander.js` — `npx aiyu-md2pdf` or `npm install -g aiyu-md2pdf`
- `--no-mermaid` — reuse existing diagrams instead of re-rendering
- `--keep-mermaid` — retain `.mmd` source files for debugging
- `--help`, `--version` — auto-generated by commander

### Features
- **Thai + English** — Sarabun font with XeTeX line breaking (no spaces needed between Thai words)
- **Mermaid diagrams** — auto-rendered to PNG (3200×2400, scale 3×) + SVG, all diagram types supported
- **Auto Table of Contents** — numbered headings (1, 1.1, 1.1.1), depth 3
- **Figure captions** — auto-generated from nearest heading or bold label
- **Cover page** — driven by YAML frontmatter (`title`, `subtitle`, `author`, `date`, `document`)
- **LaTeX-safe metadata** — frontmatter values escaped to prevent command injection
- **Page breaks** — `##` sections start on a new page; `###` flows naturally
- **High-contrast B&W** — Mermaid theme optimized for photocopying
- **Centered diagrams** — images centered on page, constrained to 85% text height

### Dependencies
- `commander@^12` — CLI argument parsing
- `js-yaml@^4` — YAML frontmatter parsing
- `@mermaid-js/mermaid-cli@11.4.2` — Mermaid diagram rendering (peerDependency)
- System: `pandoc`, `xelatex` (TeX Live / TinyTeX / MiKTeX), Sarabun font

### Testing
- **Unit tests** (46) — YAML escaping, path resolution, dependency detection; no system deps required
- **E2E tests** (10) — smoke (PDF + DOCX exist), content (page count, DOCX media, diagram count), edge cases (`--no-mermaid`, `--keep-mermaid`, no frontmatter, special chars, empty file)
- Test fixtures: `minimal.md`, `frontmatter-only.md`, `mermaid-th.md`, `special-chars.md`, `empty.md`
- Runner: `vitest`

### CI
- `.github/workflows/ci.yml` — Linux: lint (shellcheck) + unit + e2e
- `.github/workflows/ci-windows.yml` — Windows: e2e with MiKTeX
- `scripts/install-ci-deps.sh` — CI dependency installer (apt + npm)
- Build artifacts uploaded on failure
